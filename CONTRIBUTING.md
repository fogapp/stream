# Contributing

Thank you for wanting to help. This page applies to every repository under
[github.com/fogapp](https://github.com/fogapp).

## Issues are welcome

Bug reports, questions and ideas are all welcome as GitHub issues. A good
report says what you did, what you expected, what happened instead, and
which version or commit you ran.

## Security problems

Please don't open a public issue for a security problem. Use GitHub's
**Report a vulnerability** button on the repository's **Security** tab, so it
can be fixed before it's public.

## Pull requests aren't accepted for now

The projects don't take outside code yet, and pull requests will be closed
unmerged. This isn't a judgement of the change. Every line has one copyright
holder, and keeping it that way keeps open the option of offering the
software under other terms alongside its open-source license. Accepting
outside code would first need a contributor license agreement, and there
isn't one yet.

Instead, describe the change in an issue. If it's a fix, say what's wrong
and how you found it; it may well be made from your description, with credit
in the commit.

## Forks

The licenses let you fork any of these projects and change them as you like.
If you distribute a modified version or offer it to others, give it a name of
its own: see [TRADEMARKS.md](TRADEMARKS.md).
